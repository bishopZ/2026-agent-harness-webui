# One bus ride — how to use this project

This project currently has a single idea, also named **One bus ride**. Its full lifecycle artifacts (`01_brief.md` onward) sit directly in this folder rather than in a further-nested idea subfolder, since the project and its one idea share a name — matches the layout already used by this idea's sibling copy in the upstream Agent Harness repo.

Registry: this project and its idea are tracked in `priorities.json` at the repo root (`initiatives.Transit.projects["One bus ride"].ideas["One bus ride"]`), not in a Markdown registry file — see [`../../../docs/priorities-registry.md`](../../../docs/priorities-registry.md).
